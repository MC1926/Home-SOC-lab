# IT Support Portfolio

Hands-on help desk practice in my home lab: a Windows Server domain (homelab.local) with a domain controller (DC01) and a Windows client. Every ticket and runbook here was done and tested in the lab.

**Status:** In progress, started October 2026.

## Skills practiced

- Active Directory user lifecycle: onboarding, password resets, offboarding
- Group Policy, shared folders and permissions
- Networking troubleshooting: Dynamic Host Configuration Protocol, Domain Name System, ipconfig, nslookup
- Windows troubleshooting: performance, application crashes, services, printers
- Remote support, Microsoft 365 administration and ticketing
